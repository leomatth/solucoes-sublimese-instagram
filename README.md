# Sublime-se Soluções · Instagram

Posts do [@solucoes.sublimese](https://www.instagram.com/solucoes.sublimese/).

Cada pasta é um post:
- `slide-N.png`: imagens finais
- `jpg/`: versões JPEG usadas na publicação (o Instagram só aceita JPEG)
- `legenda.txt`: legenda do post
- `src/`: HTML dos slides (renderizado com o Chrome headless em 1080×1350)
